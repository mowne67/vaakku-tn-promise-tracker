# Vaakku — Tamil Nadu Promise Tracker

A source-linked prototype comparing 100 selected manifesto commitments each from Tamil Nadu's AIADMK government (2016–2021) and DMK government (May 2021–April 2026).

The headline score is strict: only commitments marked **Completed** count. Partial and unverified commitments remain visible in the ledger.

## Run locally

```sh
python3 -m http.server 4173 --directory dist
```

Open `http://localhost:4173`.

## Methodology

This is a curated 100-point sample for each government, not a full-manifesto audit. Every row links to its source or supporting public evidence so the classification can be reviewed.
